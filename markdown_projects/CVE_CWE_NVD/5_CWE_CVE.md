# CWE and CVE Difference

CWE (Common Weakness Enumeration) is a categorized list of software and hardware weakness types, or the underlying flaws that cause vulnerabilities. CVE (Common Vulnerabilities and Exposures) on the other hand is a list of specific vulnerabilities with details of how they work. For example CWE-89 is SQL injection which is a type of vulnerability and there are many CVE entries which are SQL injections for various versions of various software.

Both of these lists are important in cybersecurity - CWE for listing vulnerability types, and CVE for listing individual vulnerabilities. The former lets developers and engineers have an understanding of what type of thing to avoid, while the latter lets security teams be aware of current threats and what needs to be mitigated against.
