# Role of CWE

CWE provides a list of vulnerability types which lets software developers know what to look out for, ensuring more secure coding practices. When a developer is aware of how a vulnerability type like injection works, they can make sure to create code securely such that it wouldn't create such a vulnerabitliy - e.g. input sanatization.

The best way to ensure secure coding practices is to have trainings about CWEs relevant to your software, given to developers and engineers.
