# Relationship between CWE, CVE, and CVSS

CWE, CVE, and CVSS systems work together to ensure a common understanding of the global cybersecurity landscape. CWE helps categorize the types of vulnerabilities, CVE helps list each vulnerability so that they are all publicly know and can be defended against, and CVSS helps by assigning scores to these vulnerabilities to allow for better prioritization in organisations.

In a single organisation, the dev team can be trained to be aware of relevant CWEs and employ secure coding practices, the security team can use CVE to check for vulnerabilities in partner software, and finally CVSS can be used to plan a migitation strategy and roadmap ahead.
