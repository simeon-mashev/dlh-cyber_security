# CVE Scores

CVEs are graded in their severity level from one of the four options: low, medium, high, or critical. These levels are not arbitrary but are decided by the CVSS score of each CVE entry. The Common Vulnerability Scoring System or CVSS is used to have a consistent framework rating each vulnerability on various metrics related to how easy or difficult it is to exploit and how much potential impact it can have on a system.

Organisations must appropriately use the CVE list with the CVSS framework and severity levels to filter vulnerabilities first by whether they are related to software made or used by the company, and then by CVSS score and severity for correct prioritisation. Any big company or organisation at risk of cyber attacks should have a security team which regularly checks the CVE list for new relevant vulnerabilities and plans mitigation strategies such as patching.
