# CVE List

The CVE list is managed by the MITRE Corporation, which is a US-based organization contracted by the US Department of Homeland Security's Cybersecurity and Infrastructure Security Agency (CISA). The list is publically available globally. CVE Numbering Authorities (CNAs) are organizations authorized by MITRE to assign CVE IDs to vulnerabilities within their specific scope. Software vendors and open source projects might have their own CNAs.


The process of assigning a CVE ID is as follows:

**Step 1: Discovery:**
A vulnerability is discovered by a researcher, developer, or security company

**Step 2: Reporting:**
The discoverer reports the vulnerability to the appropriate CNA. For example if the vulnerability affects the Windows Operating System, it is reported to the Microsoft CNA.

**Step 3: CNA Validation:**
The CNA verifies that the vulnerability is real and within their scope. They also verify that it hasn't already been asigned a CVE ID.

**Step 4: CVE ID Assignment**
The CNA assigns a unique CVE ID in the format CVE-YYYY-NNNNN, where YYYY is the year and NNNNN is a sequential number for counting all vulnerabilities each year

**Step 5: Publication**
The CVE is published into the list with a description, references, and other relevant information.
