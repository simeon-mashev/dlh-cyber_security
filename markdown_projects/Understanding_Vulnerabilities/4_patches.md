# Patches

This blog post will talk about patches in the context of security and vulnerabilities

## 1. Understanding the Importance

A lot of people dislike the regular updates of the modern day such as windows updates or specific apps, however avoiding updates can be dangerous and expose you to cyber attacks. In the modern internet landscape cyber criminals, security researchers, and penetration testers constantly look for new vulnerabilities and how they can be exploited. Newly discovered vulnerabilities are published in the CVE (Common Vulnerabilities and Exposures) database, and from the moment they are discovered, they pose a huge security risk to any company or user of the vulnerable software. This is why software vendors must always try to push updates which "patch" these vulnerabilities and anyone using the software is urged to update their software with the latest patches to not be a sitting duck against cyber criminals.

Patching/Updating software is a great way to make sure you and your organization are protected against the attackers exploiting the latest vulnerabilities. It can also bring performance imporvements to the software.

## 2. Linking with Broader Security Measures

Defense in Depth (DiD) is an important concept in Cybersecurity. A cyber attack is not a simple event which turns a secure system into a "hacked" system. There are many stages to an attack including information gathering, gaining access, privilige escalation, lateral movmenet, and execution of malware. The DiD concept is the idea that an organization should protect against every single step as much as possible. Patching vulnerabilities is a way to protect against multiple steps of the attack depending on what the vulnerability is.

One potential scenario is where an attacker uses a phishing email to get an employee to click on a link. The malicious link works on a known vulnerability with a CVE, but the company has already patched it so the attack is not successful.

## 3. Looking Ahead

With the increased use of AI in all computer applications including security, paches and upates will also need to be adapted. Some AI tools have been used to discover vulnerabilities which aren't found by traditional vulnerability scanning tools, which helped software companies patch a lot of vulnerabilities at once, before attackers were able to discover and exploit them. This specific tool called Mythos by Anthropic was not publicly available so the companies could stay ahead of the attackers, but in the future organizations must be wary of attackers using AI to find vulnerabilities and generate exploit scripts much faster, so patching against these must be done on time.


## 4. Final Thoughts

I encourage all readers to reflect on the current update and patch management practices in your organisations. Patching is one of the fundamental ways to stay ahead of threats in the modern cybersecurity landscape.
